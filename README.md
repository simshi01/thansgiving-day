# День Благодарения — интерактивная страница

Люди пишут благодарности с телефона, а они всплывают на большом экране в виде пузырей iMessage.

- `/` — форма «За что ты благодарен?»
- `/messages` — большой экран с сообщениями

## Запуск локально

```bash
npm install
npm run dev
```

Откройте [http://localhost:3000](http://localhost:3000). Ничего настраивать не нужно: без Redis сообщения хранятся в памяти и пропадают после перезапуска.

Чтобы локально проверить удаление сообщений, запустите с паролем: `ADMIN_KEY=test npm run dev`.

## Выкладка

На Vercel, бесплатно, с Upstash Redis — пошагово в [ИНСТРУКЦИЯ_VERCEL.md](ИНСТРУКЦИЯ_VERCEL.md).

## Как устроено

- `app/api/messages/route.ts` — отправка (`POST`), опрос новых сообщений (`GET ?after=<id>`) и удаление по паролю (`DELETE ?id=<id>` с заголовком `x-admin-key`).
- `lib/store.ts` — хранилище: Upstash Redis, если заданы `UPSTASH_REDIS_REST_URL`/`TOKEN` или `KV_REST_API_URL`/`TOKEN`; иначе память процесса.
- `lib/anti-spam.ts` — ограничения для одного человека:
  - не чаще раза в 10 секунд, до 3 сообщений в минуту и до 15 в час;
  - нельзя повторить своё сообщение (даже слегка изменённое) в течение суток;
  - запрет ссылок и телефонов;
  - на весь зал (один IP) — до 60 сообщений в минуту.
- `lib/moderation.ts` — фильтр мата и оскорблений с защитой от обходов.
- `components/MessageContainer.tsx` — экран: раз в 3 секунды забирает новые сообщения и показывает их по кругу.
- `components/MessageBubble.tsx` — пузырь в стиле iMessage.

## Тесты фильтра

```bash
npm run test:moderation
```

Фразы для проверки лежат в `tests/moderation-cases.json`: что нужно блокировать и что нужно пропускать.
