# Как выложить сайт на Vercel (бесплатно, без карты)

Займёт около 5 минут. Понадобится только аккаунт GitHub, где лежит репозиторий `simshi01/thansgiving-day`.

> Если где-то на шаге попросят банковскую карту — **не вводи её**, остановись и напиши мне. Есть запасной бесплатный вариант.

## 1. Создать проект на Vercel

1. Открой [vercel.com/signup](https://vercel.com/signup) → **Hobby** (бесплатный) → **Continue with GitHub**.
2. На главной: **Add New… → Project**.
3. Найди репозиторий **thansgiving-day** → **Import**.
   Если его нет в списке — нажми **Adjust GitHub App Permissions** и дай Vercel доступ к этому репозиторию.
4. Ничего не меняй (Vercel сам поймёт, что это Next.js) → **Deploy**.
5. Через минуту сайт откроется по адресу вида `thansgiving-day.vercel.app`.
   Пока без базы: сообщения будут теряться. Это исправляет следующий шаг.

## 2. Подключить хранилище (Upstash Redis)

1. В проекте на Vercel открой вкладку **Storage**.
2. **Create Database** → выбери **Upstash** → **Redis** → **Continue**.
3. Тариф **Free**, регион — ближайший к вам (например, Frankfurt) → **Create**.
4. На вопрос, к каким окружениям подключить, оставь все (Production, Preview, Development) → **Connect**.

Vercel сам добавит в проект нужные переменные (`KV_REST_API_URL`, `KV_REST_API_TOKEN` и др.). Копировать ничего не нужно.

## 3. Задать пароль для удаления сообщений

1. **Settings → Environment Variables**.
2. Key: `ADMIN_KEY`, Value: длинный пароль (например, 20+ случайных букв и цифр) → **Save**.
3. Запиши пароль: он понадобится, если нужно убрать сообщение с экрана.

## 4. Перевыложить сайт

Новые переменные применяются только к новой выкладке:
**Deployments** → у последней выкладки **⋯ → Redeploy**.

## 5. Проверить

- Открой сайт на телефоне → напиши благодарность → **Благодарить**.
- На большом экране открой `https://<твой-адрес>.vercel.app/messages` — сообщение появится в течение 3 секунд.

## Как удалить сообщение с экрана

Нужен номер сообщения (`id`). Список всех сообщений с номерами:
`https://<твой-адрес>.vercel.app/api/messages`

Удаление (в Терминале):

```bash
curl -X DELETE "https://<твой-адрес>.vercel.app/api/messages?id=НОМЕР" -H "x-admin-key: ТВОЙ_ПАРОЛЬ"
```

С экранов сообщение пропадёт в течение 3 секунд.

## Сколько это выдержит бесплатно

- **Upstash Redis Free:** 256 МБ (это больше миллиона коротких сообщений) и 500 000 команд в месяц.
  - Одна отправка ≈ 12 команд.
  - Один открытый экран ≈ 2 400 команд в час, пока идут сообщения (опрос раз в 3 секунды).
    Если 10 минут ничего нового не приходит — ≈ 480 в час (опрос раз в 15 секунд).
    Свёрнутая или скрытая вкладка не тратит ничего.
  - Пример: вечер 3 часа, 2 экрана, 5 000 благодарностей ≈ 75 000 команд — около 15% месячного лимита.
- **Vercel Hobby:** только некоммерческое использование. При превышении лимитов денег не списывают: проект просто приостанавливается до сброса.
- Всё равно лучше закрывать вкладку `/messages`, когда экран не нужен.

## Если что-то не работает

- **Сообщения пропадают после обновления страницы** — не подключено хранилище (шаг 2) или не было Redeploy (шаг 4).
- **Удаление отвечает «Нет доступа»** — не задан `ADMIN_KEY` (шаг 3), не было Redeploy или пароль введён неверно.
- Логи: проект на Vercel → **Logs**.
